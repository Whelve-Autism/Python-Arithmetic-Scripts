## 脚本

- [AddTwoNums.py](./AddTwoNums.py) 读取两个数，在 `add()` 函数中转成 `float` 并输出和。
- [MultiplyThreeNums.py](./MultiplyThreeNums.py) 读取三个数并输出乘积。

<a id="quick-start"></a>
## 快速开始

使用 Python 3 运行任意一个脚本，按提示逐个输入数字。两个脚本均只用到 Python 自带的功能。

```bash
python3 AddTwoNums.py
python3 MultiplyThreeNums.py
```
