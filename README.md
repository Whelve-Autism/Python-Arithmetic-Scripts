# Python Arithmetic Scripts

**Numeric input · Addition · Multiplication**

Two short Python programs that read numbers from the terminal, perform an arithmetic operation, and print the result.

## Scripts

- [AddTwoNums.py](./AddTwoNums.py) reads two values, converts them to `float` inside `add()`, and prints their sum.
- [MultiplyThreeNums.py](./MultiplyThreeNums.py) reads three values and prints their product.

<a id="quick-start"></a>
## Quick start

Run either script with Python 3 and enter a number at each prompt. Both use the standard library.

```bash
python3 AddTwoNums.py
python3 MultiplyThreeNums.py
```
